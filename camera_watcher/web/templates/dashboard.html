New camera

All cameras share one data root -- clips, cache, and retention are managed fleet-wide (see Fleet Settings), not per camera. A camera starts recording immediately once added, even before you've finished tuning motion sensitivity or drawing an ignore mask -- open its page any time to adjust those.

Web UI binding

"tailscale" resolves this host's Tailscale IPv4 address at startup and binds only there -- fails loud rather than falling back to a public/LAN interface. Set an explicit literal host (e.g. "127.0.0.1") to bind somewhere else instead. Changes here take effect on the next restart, not immediately -- use Stop Server above once deployed with Restart=always.

Retention

Applies live, no restart needed -- the next scheduled sweep (or a manual run below) always uses whatever's saved here. A clip's tier (low/review/high) comes from the clip classifier's verdict, if one's configured -- see the Classifier tab.
